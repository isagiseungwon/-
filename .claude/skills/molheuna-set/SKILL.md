# 몰흐나 오늘의 세트

주제 한 줄 → 블로그 + 릴스 대본 + 카드뉴스를 한 번에 만든다.
목표는 동네에서 검색하는 사람이 몰흐나를 발견하고 예약하게 만드는 것이다.

## 진행 순서

1. 같은 폴더의 `molheuna-facts.md` 를 읽는다. 이게 유일한 사실 출처다.
2. 사용자의 주제 한 줄을 받는다. 없으면 "오늘 어떤 주제로 갈까요?" 하나만 묻는다.
3. 아래 순서로 만든다. 같은 이름의 스킬이 있으면 불러서 쓰고, 없으면 직접 쓴다.
   - 블로그: `molheuna-blog` (복붙용 본문, 사진 배치표, 태그)
   - 릴스 대본: `harry-reels-planner` 또는 `jachung-primal-planner`
   - 카드뉴스: `instagram-cardnews`
4. 세 결과를 한 화면에 이어서 보여준다. 각 결과는 `## 1. 블로그`, `## 2. 릴스 대본`, `## 3. 카드뉴스` 로 나눈다.
5. 맨 끝에 `## 확인필요 목록` 을 붙인다.

## 사실 규칙 (가장 중요)

- 좌석 수, 운영시간, 무인 시간대, 요금, 결제·예약 경로, 도보 시간은 **facts 파일에 적힌 값만** 쓴다.
- 값이 `?` 이거나 비어 있으면 숫자를 지어내지 않는다. 그 자리에 `【확인필요: 항목명】` 을 남긴다.
- 끝의 `확인필요 목록` 에 본문에 남은 【확인필요】 항목을 모아서 보여준다. 하나라도 남아 있으면 "이 상태로는 올릴 수 없어요, 위 항목을 채워주세요"라고 말한다.
- 후기, 이용자 수, 수상 경력, 할인 같은 근거 없는 내용은 만들지 않는다.

## 규칙

- 말투와 구조는 호출한 각 스킬의 규칙을 따른다.
- 세 채널(네이버 플레이스·블로그·인스타)에 같은 사실 정보가 들어가도록 맞춘다.
- 쉬운 말로 짧게 안내한다. 사용자는 개발 초보다.
