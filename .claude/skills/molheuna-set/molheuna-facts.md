# 몰흐나 사실 정보 (여기만 고치면 모든 글에 반영됨)

쌍문역 무인 스터디카페 몰흐나. 운영은 누나(사장님), 채널은 네이버 플레이스·블로그·인스타.
`?` 또는 `확인필요`로 적힌 칸은 지어내지 않고 글에 【확인필요】로 남긴다.
(2026-10-09 승원이 직접 알려준 내용 기준)

## 공간 구성
- 큰방: 소파 1개, 1인 의자책상 1개, 2인용 책상 1개, 1인 책상 1개
- 작은방: 책상 1개, 의자 2개 (거의 혼자 쓰는 편)
- 총 좌석 수: 확인필요 (위 구성을 합산해 숫자로 단정하지 말 것. 소파와 2인용 책상의 인원 기준 미확정)

## 운영시간
- 매일 18:00 ~ 다음날 02:00
- 사장님이 낮에 약 1시간 청소하러 방문 (시간 미정, 글에 쓰지 말 것)
- 무인 시간대: 확인필요 (운영시간 중 상주 직원이 없는지 미확인)

## 요금
- 작은방 단독 이용: 1시간 3,000원
- 하루종일 이용권: 4,500원 (확인필요: 작은방 전용인지, 전체 공간 공통인지)
- 세 번째 요금: 확인필요 (현재 확인된 요금은 2종)

## 예약·위치
- 결제·예약 경로: 확인필요
- 쌍문역에서 도보 몇 분: 확인필요
