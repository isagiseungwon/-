# 몰흐나 경쟁 분석

사용자에게 캡처나 숫자를 요구하지 말고, 도구로 직접 모아서 분석한다.

## 진행 순서

1. 환경변수 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 이 설정돼 있는지 확인한다. 값은 출력하지 않는다.
   - 없으면 **파일 모드**로 간다. 사용자가 네이버 블로그 탭에서 복사한 제목들을 붙여넣게 하고, `titles.txt` 에 한 줄에 하나씩 저장한 뒤 `python tools/competitor_analysis.py --file titles.txt` 를 실행한다. 3번 이후는 같다.
   - 사용자가 API 키를 이미 갖고 있을 때만 `tools/README.md` 를 안내한다. 키가 없다고 멈추지 않는다.
2. 검색어를 정한다. 사용자가 주면 그것, 없으면 기본값으로
   `쌍문 스터디카페`, `쌍문역 무인 스터디카페`, `수유 스터디카페` 를 쓴다.
3. 아래 명령을 실행한다.
   `python tools/competitor_analysis.py "검색어1" "검색어2"`
4. 저장된 `reports/competitor-*.md` 를 읽는다.
5. 결과를 아래 형식으로 요약한다. 요약은 20줄 안쪽으로 한다.

## 보고 형식

- **상위 글의 공통 패턴**: 자주 쓰는 단어, 제목 패턴 비율, 평균 제목 길이
- **비어 있는 자리**: 상위 글에 거의 없는데 몰흐나가 말할 수 있는 것 (예: 무인 시스템, 심야, 동네 특성)
- **추천 제목 5개**: 위 분석에 근거한 제목. 몰흐나 사실은 `.claude/skills/molheuna-set/molheuna-facts.md` 에 적힌 것만 쓴다. 빈 값은 지어내지 않는다.
- **다음 단계**: 고른 제목으로 `/molheuna-set` 을 돌리라고 안내한다.

## 규칙

- 분석에 없는 순위나 검색량을 지어내지 않는다. 도구가 주지 않은 숫자는 "이번 도구로는 알 수 없음"이라고 말한다.
- 비로그인 공개 데이터와 공식 API만 쓴다. 네이버 화면을 긁어오는 방식은 쓰지 않는다.
- 키 값을 출력하거나 파일에 저장하지 않는다.
